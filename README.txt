SHINRA TYPEWRITER
=================
Plays the FFXIV "Keyboard Square" typing event for you: it reads the word boxes on
screen and types them, pressing Enter after each one.

HOW TO USE
 1. Run the game in Windowed or Borderless Windowed mode.
 2. Open ShinraTypewriter.exe.
    - If Windows says "Windows protected your PC": click "More info" -> "Run anyway".
      (The app isn't signed. It reads your screen and presses keys, which some antivirus
      tools flag, so you may need to allow it.)
 3. In the app, pick the screen the game is on.
 4. Click into the game so the typing box has focus, then press Ctrl+Alt+S to start.
    Press Ctrl+Alt+S again to stop.

WHAT IT TYPES FIRST
 Green boxes, then red boxes, then everything else (closest enemies first). You can
 turn the green/red priority off in the app. A word isn't retyped for 2 seconds after
 it's typed (adjustable). Nothing is typed while the game shows "Inputs disabled!".

SETTINGS
 - Delay between keys / Pause before Enter: raise these if letters get dropped or
   Enter lands before the word finishes; lower them to type faster.
 - Type capital letters: turn off if you'd rather it type everything lowercase.
 Settings are saved in Documents\Shinra Typewriter.

IF IT MISSES WORDS
 Press Ctrl+Alt+D during a fight (or click "Debug snapshot"). It opens a picture:
 green boxes = words it will type, red boxes = skipped (with the reason).

TROUBLESHOOTING
 - Nothing gets typed: make sure the game window has focus. If the game runs as
   Administrator, run ShinraTypewriter.exe as Administrator too.
 - Hotkeys don't work: use the Start button, then click back into the game.

Note: automating gameplay is against the FFXIV terms of service. Use at your own risk.
